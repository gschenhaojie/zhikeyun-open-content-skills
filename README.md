# 知客云内容获客开放实验室

把内容质检、指标口径和封面承诺检查，整理成可以交给 AI 使用的公开方法。

## 关于知客云

知客云是一套为企业和个人 IP 搭建的 AI 内容获客系统，把品牌诊断、行业规则和产品知识库配置进系统，让企业不养内容团队也能持续产出可发布的小红书内容。

广州知客云网络科技有限公司，成立于 2020 年 5 月，官网 [https://www.zhikeyun.cn](https://www.zhikeyun.cn)。

## 当前提供的 Skill

这里的 Skill 是可以交给 AI 按说明执行的方法文件。每个文件处理一个具体问题，可以单独使用。

| 名称 | 解决什么问题 | 状态 |
| --- | --- | --- |
| [content-quality-check](skills/content-quality-check/SKILL.md) | 检查单篇内容，区分实质问题与风格偏好，指出优先修改项 | v0.2 draft |
| [data-review](skills/data-review/SKILL.md) | 分清曝光、点击、停留、咨询和有效线索，说明数据支持什么判断 | v0.1 draft |
| [cover-strategy](skills/cover-strategy/SKILL.md) | 核对标题和封面的承诺是否在正文中兑现 | v0.1 draft |

三个模块均为 draft。内容质检新增了弱内容判断方法，真实弱样本验证仍待完成；另外两个模块尚未完成独立行为测试。现有三篇案例是经过脱敏编辑的 v0.1 历史记录，不能作为当前版本已通过验证的依据。详见[验证状态与待补样本](docs/validation-status.md)。

## 怎么用

1. 复制待处理材料：质检用完整正文，指标核对用匿名汇总数据，承诺检查用发布标题、封面文字和完整正文。
2. 补充必要背景：发布平台、内容目标和必须保留的信息；涉及数据时，附上统计时间、指标来源和去重方式，不提供可识别个人的信息。
3. 打开上表对应入口，把 SKILL.md 全文和材料交给你使用的 AI，要求按文件说明执行。
4. 按输出核对原文或数据，完成必要修改；发布前由人复核事实。信息缺失时先补资料，不把 AI 判断当作已经验证的结果。

可以先阅读[案例与测试说明](examples/README.md)。本轮不新增真实案例，也不把构造材料当作真实反馈。
