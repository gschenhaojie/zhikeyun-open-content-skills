# 知客云内容获客开放实验室

> 把真实经验，变成客户能够理解、信任并采取行动的内容。

这是由广州知客云网络科技有限公司发起的长期公共项目。

项目面向所有依赖专业知识和信任完成交易的人，包括：

- 中小企业经营者
- 销售、顾问和专业服务者
- 内容运营与营销从业者
- 独立开发者和一人公司
- 需要公开表达专业经验的创作者

很多人并不缺少专业经验，真正困难的是把分散在产品、销售、服务和项目中的经验，转化成客户愿意点开、能够理解、产生信任并采取行动的内容。

## 内容质检 Skill Open v0.1

当前状态：`draft`。已提供[可试用的 Skill 入口](skills/content-quality-check/SKILL.md)、构造测试和[三篇授权真实案例](examples/content-quality-check/public/README.md)。当前尚未覆盖“明显较弱真实内容”的验证门槛，不是 `beta`、`stable` 或正式发布版本。

它只解决一个问题：检查一篇待发布内容，给出发布结论和最多三项优先修改建议。普通用户不需要先理解 Skill 技术概念，可以按以下四步试用：

1. 复制一篇待检查内容；
2. 补充发布平台、内容目标和必要约束；
3. 调用“内容质检 Skill Open”；
4. 按优先级完成修改并在发布前复核事实。

## 项目是什么

知客云内容获客开放实验室研究并分享免费、可复用的内容获客方法。项目会把诊断、选题、写作、质检和复盘方法逐步整理为专业 Skill——也就是“把诊断、选题、写作、质检和复盘方法固化成 AI 可以执行的专业规则”。

这个仓库会优先完整解决若干窄而真实的问题，而不是公开一套残缺的企业系统样品。

知客云内容获客开放实验室不是新的正式商业产品名称；知客云当前正式产品名称仍为“知客云 AI 内容获客系统”。

## 适合谁

如果你有真实的产品、服务或项目经验，却难以稳定地把它们转化成客户看得懂、信得过、愿意继续行动的内容，这个项目可能适合你。你不需要先理解复杂的 AI 架构，也可以从具体问题和使用说明开始。

## 用户未来能获得什么

首个可用版本发布后，用户应能在约 15 分钟内：

- 判断一篇内容是否适合直接发布；
- 找出最影响质量的最多三个问题；
- 识别“正确但无用”的空泛表达；
- 获得具体修改方向和修改示例。

## 当前状态

- 仓库基础结构已建立。
- “内容质检 Skill Open v0.1”已实现 `draft`，可用于有限试用。
- 10 个构造案例和 3 个授权真实案例已完成隔离前向测试；真实测试后修订一次规则，并完成全部 10+3 回归。
- 三篇真实内容最终均被合理判断为可以发布，尚未覆盖“明显较弱真实内容”的问题识别验证，因此不升级为 `beta`。
- 当前状态不代表 `stable` 或正式发布，也不构成效果保证。

## 首个公开模块

首个模块是“内容质检 Skill Open v0.1”，目标是判断一篇内容能否直接发布，并指出最多三项最应该优先修改的问题。

当前提供[可运行的 draft Skill](skills/content-quality-check/SKILL.md)、[构造测试资料](examples/content-quality-check/README.md)与[授权真实案例](examples/content-quality-check/public/README.md)。这些材料可用于试用和验证，但不应被描述为已正式发布。

## 项目原则

项目坚持真实经验优先、事实与判断分开、不编造案例和数据、输出具体可执行，并根据真实使用反馈持续修订。完整原则见 [docs/principles.md](docs/principles.md)。

## 公开能力和企业级能力的边界

免费公开模块会完整解决一个窄问题；企业级服务解决企业知识库、行业适配、工作流编排、持续复盘、个性化校准和交付责任。公开仓库不等于完整的“知客云 AI 内容获客系统”。详细边界见 [docs/public-private-boundary.md](docs/public-private-boundary.md)。

## 仓库结构
