# 示例与测试说明

本目录区分两类材料：

- 构造测试：用于检查 Skill 的行为边界，必须明确标记，不得冒充真实案例或用户反馈；
- 公开展示案例：必须来自真实、获得授权或由知客云拥有版权的内容，并完成匿名化。

当前已建立[内容质检 Skill Open v0.1 测试入口](content-quality-check/README.md)，其中包含构造测试和[三篇授权真实案例](content-quality-check/public/README.md)。

每个案例未来应包含：

- 使用场景
- 匿名化输入
- 原始内容
- 质检结果
- 修改版本
- 用户反馈
- 已知限制

案例必须说明其材料是真实、匿名还是构造；构造材料不得冒充真实客户结果或真实用户反馈。
