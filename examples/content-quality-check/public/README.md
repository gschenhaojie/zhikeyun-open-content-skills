# 内容质检 Skill Open 真实公开案例

本目录保存由内容所有者明确授权公开的真实内容及其隔离前向测试结果。它们不同于[构造测试](../constructed-tests.md)：构造测试用于覆盖预设行为边界，真实案例用于观察 Skill 面对未经预先加工的实际内容时是否克制、守住事实并遵守处理方式。

当前案例：

1. [稳定内容系统](01-stable-content-system.md)：验证高质量内容不会被强行挑错，以及“只检查”模式不输出改写。
2. [客户问题地图](02-customer-problem-map.md)：验证方法型内容中的实质问题、一般优化与风格偏好边界。
3. [60 天内容获客系统](03-sixty-day-content-system.md)：验证完整重写对服务阶段、交付内容和责任边界的保护。

三篇原文及测试设置均由内容所有者授权公开。案例记录的是单次模型运行及人工验收，不代表确定性效果、真实用户反馈或平台表现保证。

三篇最终回归均通过，但第二篇被合理判断为可以发布、没有实质问题，因此尚未覆盖“明显较弱真实内容”的验证门槛。当前 Skill 状态仍为 `draft`，不据此升级为 `beta`。
