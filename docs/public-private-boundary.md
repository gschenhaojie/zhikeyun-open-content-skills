# 公开能力和企业级能力边界

公开仓库的目标是完整解决若干窄而真实的问题，同时保护客户权益、企业知识和生产级交付方法。

| 公开仓库可以包含 | 不得公开 |
| --- | --- |
| 通用判断框架 | 生产级总控 Skill |
| Open 或 Lite 版本 Skill | 完整行业知识库 |
| 空白模板 | 企业知识库 |
| 匿名且获得授权的案例 | 客户原始资料 |
| 使用说明 | 销售话术 |
| 修改前后示例 | 服务交付管理规则 |
| 通用质检规则 | 企业个性化校准规则 |
|  | 自动路由和反馈闭环 |
|  | 未经授权的案例、数据和素材 |
|  | 私人仓库、路径、密钥或环境信息 |

## 两种交付解决的问题不同

免费产品应完整解决一个窄问题，让使用者能独立获得真实价值，而不是把核心步骤故意留空。

企业服务解决企业情境、行业适配、系统组合、持续优化和结果责任。它需要结合企业自己的产品、客户、案例和表达方式，并由人持续复核和校准。因此，公开仓库不是完整的“知客云 AI 内容获客系统”，也不能替代企业级交付。
