## 历史记录如何使用

v0.1 历史文档记录过 10 个构造案例和 3 个授权真实案例回归。三篇真实内容最终均无优先修改项，未覆盖明显较弱真实内容。

本轮对三篇真实案例的输入、输出做了脱敏整理；第三篇另去除服务周期、阶段时间和具体交付安排。原有构造材料也移除了金额与结果数字，并编辑部分措辞。它们都没有重新运行，旧轮次通过记录不能转移给编辑稿或 v0.2。

历史文件只用于说明曾观察到的问题与修订缘由，不再声称是逐字原始模型输出。完整旧记录仍可在仓库历史中追溯；本轮没有改写 Git 历史。

## 脱敏范围

三个公开方法仅保留通用检查与口径，不包含内部业务评分、账号配置、行业词表、沟通脚本或服务安排。案例去除了身份与品牌关联；仅保留说明历史观察所需的方法关系。第三篇删除的安排不能据当前整理稿复原。

项目自有名称只保留在项目介绍、版权与品牌权利说明等必要位置，不进入三个 Skill 或案例正文。敏感性无法确认的服务内容已删除或中性化，不作为可公开事实保留。
