# 公开 Skills

专业 Skill 是“把诊断、选题、写作、质检和复盘方法固化成 AI 可以执行的专业规则”。本目录用于保存公开模块的规格、说明和未来正式版本。

## 状态标签

| 状态 | 含义 |
| --- | --- |
| `planned` | 已确定问题和范围，尚未提供可用版本 |
| `draft` | 正在编写和内部验证，不建议正式使用 |
| `beta` | 已可试用，规则和输出仍可能明显变化 |
| `stable` | 已通过发布门槛，适合按说明稳定使用 |
| `deprecated` | 不再推荐使用，并提供替代方向或迁移说明 |

## 正式模块的最低文档要求

每个正式 Skill 未来至少需要说明：

- 解决的问题
- 适用对象
- 输入要求
- 使用方法
- 输出结构
- 示例
- 已知限制
- 版本信息
- 许可证说明

当前规划模块见[内容质检 Skill Open](content-quality-check/README.md)。
