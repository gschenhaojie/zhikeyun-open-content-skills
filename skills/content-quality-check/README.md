# 内容质检 Skill Open

> **当前状态：`planned`。当前文件是规格说明，不是可直接运行的 Skill。**

## 目标

判断一篇内容能否直接发布，并指出最应该修改的三处。

## 预计输入

必需信息：

- 平台
- 目标
- 原始内容

可选补充：

- 行业
- 目标用户

## 预计输出

- 是否可用
- 主要问题
- 三个优先修改点
- 修改示例

## 发布门槛

- 至少三组真实或获得授权的匿名测试案例
- 不编造数据、案例或用户反馈
- 公开能力和企业级能力边界说明完整
- 人工复核通过

在以上门槛全部通过并发布可用版本前，本目录不声称能够完成内容质检。
