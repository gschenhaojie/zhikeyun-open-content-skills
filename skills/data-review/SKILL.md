# 内容数据的指标口径

版本：v0.1 · 状态：draft · [许可](../../LICENSE)

## 1. 解决什么问题

多数团队没有先区分曝光、点击、停留、咨询与有效线索，就把前一层的数量当成后一层的结果。本方法只检查口径与证据是否对应，帮助回答“这份数据记录了什么、还不能证明什么”。不据此设计投放或经营策略。

## 2. 输入与输出

输入匿名汇总表及待回答的问题。每个指标尽量附上来源字段、统计时间、时区、次数或人数、去重规则；比例还需分子、分母及其人群范围。咨询和有效线索使用匿名计数与判定规则，不输入个人标识、主页地址或对话全文。

先核对同名指标是否同义、时间是否一致、分母是否对应、缺失项是否被误记为零，再决定能否比较。缺失用“未知”或 null 表示；分母缺失或为零时，不计算比例。不同计数单位不能直接相除当作人员转化率。

输出一张口径核对表，列出指标、定义、来源、窗口、计数单位和已知缺口；随后分别写出可直接观察的事实、可比与不可比项，以及当前不能成立的结论。数据不够时明确写“无法判断”，不要把缺失层推算成已发生的结果。

## 3. 口径定义

下表是核对框架，实际字段必须以数据源说明为准。某层没有数据就保留为空，不假设每位用户依次经过全部环节。

| 层级 | 一句可核对的定义 |
| --- | --- |
| 曝光 | 数据源按其展示规则记录的内容展示次数或去重人数，须注明两者中的哪一种。 |
| 点击 | 数据源记录的进入内容动作次数或人数，不自动等于阅读完成；若只提供“阅读”字段，按其原始定义记录，不能自行改名为点击。 |
| 停留或翻页 | 内容打开后记录的可观察消费行为，需注明是停留时长、平均时长、翻页次数还是完读，不能彼此替代。 |
| 收藏或分享 | 数据源记录的收藏、转发或分享动作，两项分别计数，不能据此确认用户已有需求。 |
| 主页访问 | 数据源按其统计规则记录的主页打开次数或人数，只有具备归属记录时才能对应到某篇内容。 |
| 关注 | 统计窗口内记录的关注动作或新增关注人数，须与取关及净增区分。 |
| 咨询 | 用户主动提出相关问题或表达进一步了解意愿，按事先说明的规则记录次数或去重人数，排除无关消息。 |
| 有效线索 | 在去重咨询中，依据预先声明且可核对的相关需求与后续沟通条件完成确认的对象，不能仅凭点赞、关注或发消息认定。 |

咨询与有效线索没有跨团队通用的自动判定标准。先说明业务相关性、排除规则、由谁确认及何时确认，再比较汇总数量；保留“待确认”，不能将其全部记为有效。

## 4. 已知限制

样本少、时间窗口短或缺少逐条归属记录时，不能据此判定稳定差异、定位某个标题或段落的作用、证明因果、预测后续结果，或比较不同人群中的优劣。只有汇总数据时，不能还原具体用户的流转路径。

不同平台、自然分发条件或计数方式下的指标不能直接合并。停留均值不能代替消费行为分布；咨询增加也不能证明有效线索增加。本文不预设合格率或固定换算关系。
